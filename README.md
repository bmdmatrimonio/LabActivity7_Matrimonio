## Lab Activity 7: Data Mining APIs and Interactive Data Visualization
**Description**
    This project fetches live environmental metrics (hourly temperature and solar irradiance) from an open REST API, processes the raw JSON data using `pandas`, exports it to a structured CSV, and generates an interactive dual-metric line visualization using `plotly`.

**Required Libraries**
Install the necessary packages via terminal:
pip install pandas requests plotly

## How to Run
1. Open your terminal or Command Prompt.

2. Navigate to the project directory:
    `cd lab_activity_7`

3. Run the script:
    `python data_visualization.py`
